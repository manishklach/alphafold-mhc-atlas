# v0.10.0 - Pilot Workflow Foundation

This milestone turns the repository into a serious local-first pilot workflow seed for structure-guided experimental prioritization.

## What the platform can now do

- organize multiple projects into a workspace
- preserve project history and change summaries
- generate weekly review packets
- export scientist, computational lead, and manager views
- produce meeting-ready decision packets
- carry forward shortlist, review, feedback, and handoff context
- keep all outputs evidence-linked and caveat-aware

## What the golden demo shows

The golden demo walks a reviewer through:

1. workspace overview
2. changes since last review
3. weekly review packet
4. role views
5. shortlist and next actions
6. decision packet

## Scientific scope

Conservative by design:
- not a binding affinity predictor
- not an immunogenicity predictor
- not proof of mechanism
- not a substitute for experimental validation
- residue overlap is not treated as canonical equivalence without explicit mapping

## Intentionally out of scope

- cloud-heavy collaboration
- generic project management
- black-box recommendation systems
- claims of biological validation
