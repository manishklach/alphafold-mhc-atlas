Start Your Own Project

This repo is not just for demos. The shortest researcher path is: copy the researcher template, add trusted allele sequences and WT peptide(s), generate FASTA inputs, run AlphaFold or ColabFold outside this repo, then rerun analysis and inspect the resulting project.

  1. Start from examples/researcher_project_template.yaml.
  2. Provide real heavy-chain and beta-2 microglobulin sequences directly or via data/allele_reference.yaml.
  3. Run mhc-atlas run --config examples/researcher_project_template.yaml.
  4. Place prediction outputs under outputs/<project>/predictions/ and rerun the same command.
  5. Open the result with mhc-atlas app --project outputs/my_peptide_mhc_project.

Guides: MY_FIRST_PROJECT.md and docs/NEW_RESEARCHER_GUIDE.md
