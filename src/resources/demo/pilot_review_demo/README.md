# Pilot Review Demo

This demo extends the cross-allele toy project with pilot-review artifacts.

Included:

- disruptive shortlist scenario export
- review queue and shortlist
- feedback and annotation examples
- checklist run
- handoff bundle with explicit caveats

Suggested walkthrough:

1. Run `mhc-atlas app --demo pilot_review_demo`
2. Open `Review Queue` and inspect the shortlisted row
3. Open `Feedback` and `Notes`
4. Open `Handoff Exports` and inspect `pilot_bundle`
