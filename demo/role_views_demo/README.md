# Role Views Demo

This demo focuses on the three role-oriented exports:

- scientist / analyst
- computational lead
- manager / reviewer

Suggested commands:

```bash
mhc-atlas role-view export --project demo/pilot_review_demo/project --role scientist
mhc-atlas role-view export --project demo/pilot_review_demo/project --role comp_lead
mhc-atlas role-view export --project demo/pilot_review_demo/project --role manager
```
